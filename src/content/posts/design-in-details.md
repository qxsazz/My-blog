一个好的界面，往往不会在第一眼就告诉你它做了多少事。它只是让你觉得舒服，知道下一步该做什么。

## 先建立阅读的节奏

文字的大小不是孤立的数字。标题、正文、注释之间需要建立关系，行距和段落间距则决定呼吸的节奏。

我喜欢从正文开始：选择一个舒适的字号，设定行高，再向上推导标题，向下推导辅助信息。

| 用途 | 桌面字号 | 行高 |
| --- | --- | --- |
| 首页主标题 | 40px | 1.5 |
| 区块标题 | 26px | 1.4 |
| 文章正文 | 17px | 1.95 |
| 辅助信息 | 12px | 1.6 |

## 颜色也是语气

深蓝色的背景像夜晚，银白色的文字像远处的光。冰蓝色只在需要引导视线的地方出现，让页面保持清楚而安静。

```css
:root {
  --paper: #050b18;
  --ink: #e6f1ff;
  --accent: #7bcfff;
}
```

## 让动效服务于理解

动效的作用是解释变化，而不是不断索取注意力。一个轻微的位移，一次自然的淡入，就足够让页面有生命力。

同时，要记得尊重用户减少动态效果的偏好。安静，也是一种完整的体验。
