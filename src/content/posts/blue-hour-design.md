夜晚的颜色不是单一的黑。远处的光、空气里的蓝、近处物体的轮廓，会组成丰富却安静的层次。

把这种感觉带进界面时，我更在意的是阅读，而不是装饰。

## 先让文字清楚

背景可以足够深，但文字不需要使用刺眼的纯白。略带蓝调的银白色，能让长时间阅读柔和一些。

正文、摘要和日期应该有清楚的对比。辅助文字可以退后，但不能小到需要用力辨认。

## 把强调色留给重要的动作

冰蓝色适合用来标记当前导航、可点击的链接和重要提示。页面上的每一处发光，都应该有一个理由。

```css
:root {
  --paper: #050b18;
  --ink: #e6f1ff;
  --accent: #7bcfff;
}
```

## 让动态有停下来的余地

缓慢的光晕与稀疏的星点，可以给页面带来一点呼吸感。但阅读不应该依赖它们。关闭背景效果后，页面仍应拥有清楚的层次。

好的装饰，是让人记住氛围，也让人能够专心读完文字。
