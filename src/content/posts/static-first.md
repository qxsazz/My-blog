不是每个网站都需要一个一直运行的服务器。

对于个人博客，内容的变化频率远低于阅读频率。把页面提前生成，放在任何一个静态托管平台上，就能获得轻巧、可靠的体验。

## 把复杂留在构建时

静态生成并不意味着放弃交互。搜索、主题切换、导航等小功能，依然可以在浏览器里完成。

Astro 的组件默认生成 HTML，只有确实需要交互的地方才添加脚本。这让「先把内容展示好」成为自然的起点。

## 一份可以带走的内容

Markdown 文件很普通，普通到任何编辑器都能打开。这也是它最好的地方。

```text
src/
├── content/       # 文章和手记
├── components/    # 可复用的界面
├── layouts/       # 页面骨架
├── pages/         # 静态路由
└── styles/        # 设计变量与样式
```

我希望未来换一种工具时，文字还能原样带走。网站会变，记录留下。
